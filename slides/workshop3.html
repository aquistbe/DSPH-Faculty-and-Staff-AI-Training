IN EVERY TOOL

The Four Parts of a Reusable Assistant

Instructions

What it does, the format it uses, and the tone.

Reference files

The files it works from, such as a template, style guide, or deadline list.

Tools

What it can do besides write, such as search the web or run on a schedule.

Guardrails

What it must refuse, and when it sends you to a person.

I recommend writing the instructions and guardrails in a Word document first, then pasting them into the tool. When a tool changes, as custom GPTs just did, you still have your instructions.

Stuck? Give the AI your documents and ask it to draft the instructions, then edit them.

Make a Plugin in ChatGPT Edu

  1. 1Optional: copy the instructions into a Word document and save it.
  2. 2Start a new chat, type @, and choose Plugin Creator.
  3. 3Copy the instructions from the workshop page, paste them in, and attach the file(s) with +.

OTHER USES

What Else Plugins Are Good For

Plugins work best for tasks that repeat, follow a set format, and rely on a document you already have.

AreaExamples
AdminMonthly project updates in a template · seminar announcements in school style · answers from a deadline or policy list
TeachingFeedback drafts based on your rubric (you edit them; no student names or grades) · syllabus text for Canvas · checking assignment instructions for gaps
ResearchLab style guide applied to drafts · checklist review (e.g., STROBE) of a methods section you wrote · reviewer-style critique of your own aims
DepartmentOne shared “house style” skill so recaps and announcements look the same

ChatGPT can also use a plugin's instructions in a regular chat when your request matches, without opening the plugin. Test it the same way, and use only fictional or approved data.

ACTIVITY 2 · BEFORE YOU SHARE

Is This Assistant Advisory Only?

What to expect
  • Most assistants pass the first test.
  • Many fail the second test when you ask again.
  • The third test is where they are most likely to make something up.
  • A wrong grant date could cost you a submission, so someone needs to check every date.
Before you share a plugin
  • Share it only within the Drexel workspace, with specific people.
  • Make sure everyone you share with can see the reference files.
  • Run the three tests again after any change.
  • Put your name on it and a date to review it.

ACTIVITY 3 · ~12 MIN

Choose a Task to Schedule, and Set One Up

A scheduled task runs a prompt at a set time and sends you the result. It is useful for a small number of routine tasks.

ACTIVITY 3 · THE TEST

When a Task Is Worth Scheduling

It repeats

It happens on a regular schedule, such as weekly or monthly.

Public information

It uses public sources or only what is in the prompt. Scheduled tasks cannot read your Project files.

You will read it

If you won't read the results, there is no reason to run it.

Low stakes

A wrong result would not cause harm, and no one else acts on it.

ACTIVITY 3 · PART B · 8 MIN

Set Up One Scheduled Task

  1. 1In ChatGPT Edu, open Scheduled in the left sidebar.
  2. 2Paste in the prompt and fill in your topic and an end date.
  3. 3Check the name, day, time, time zone, and frequency.
  4. 4Turn on notifications in Settings → Notifications.
  5. 5When it runs, open every link before you use the results.
The promptEvery Monday at 8 AM Eastern, search PubMed and the web for articles published in the past 7 days on [your topic]. List up to 5, with title, journal, publication date, and link. Only include articles you can link to. If there is nothing new, say "Nothing new this week." Stop running this task on [date three months from today].
Check it monthlyPut a monthly reminder on your calendar to look at the results, and pause or delete the task if you are not using it.

ACTIVITY 3 · LIMITS

Scheduled Tasks: What to Know

ChatGPT Edu
  • You can have up to 10 active tasks, and they can run at most once an hour.
  • A task created in a Project cannot read the Project's files.
  • Each run counts toward your usage, even if there is nothing to report.
  • Results go only to you. Do not use tasks to send messages to other people.
  • Pause or delete tasks you are no longer using.
Copilot, and other ideas
  • Copilot Chat: scheduled prompts require the paid license, which Drexel does not have.
  • Check a funder's announcements page each month.
  • List new state or city reports on a policy you follow each week.
  • Find recent articles for a course reading list each term.

WRAP-UP

What to Take Away

Keep your instructions in a Word document, test an assistant before you share it, and only schedule tasks you will use.

  • In ChatGPT Edu, plugins replace custom GPTs. If you have custom GPTs, copy the instructions before December 11.
  • Test each assistant with a question it should refuse, a follow-up asking again, and a question it can't answer from its files.
  • Schedule a task only if it repeats, uses public information, you will read it, and a wrong result would not cause harm.
  • Use Claude and other personal tools with Low Risk Data only.
