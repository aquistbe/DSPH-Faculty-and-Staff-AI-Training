IN EVERY TOOL

The Four Parts of a Reusable Assistant

Instructions

What it does, the format, the tone.

Reference files

What it works from: a template, a style guide, a deadline list.

Tools

What it can do besides write: search the web, run on a schedule.

Guardrails

What it must refuse, and when it sends you to a person.

Write the instructions and guardrails in your own Word document first. Then paste them into the tool. Tools change; your document doesn't.

ACTIVITY 1 · ~17 MIN

Build a Reusable Assistant

One assistant, from your instructions and a reference file. Pick Build A or Build B.

ACTIVITY 1 · HOW TO

Make a Plugin in ChatGPT Edu

  1. 1Paste your build's instructions into a Word document first. Save it.
  2. 2New chat. Type @, choose Plugin Creator.
  3. 3Paste the instructions. Attach the reference file(s).
  4. 4Answer its questions. Read the final instructions; fix anything it changed.
  5. 5To use it: new chat, type @, pick your plugin.
No Plugin Creator?
  • ChatGPT Edu Project: paste the instructions into Project instructions; upload the files to the Project.
  • Copilot Chat: look for Create an agent. Paste the instructions; paste the reference text into the chat each time.
  • New plugins start private. Only you can use it until you share it.

ACTIVITY 2 · BEFORE YOU SHARE

Is This Assistant Advisory Only?

What usually happens
  • Most assistants pass Test 1.
  • Many fail Test 2. A polite push often works.
  • Test 3 is where they make things up.
  • A wrong grant date can cost a submission. So a person checks every date before acting.
Before you share a plugin
  • Inside the Drexel workspace, with specific people.
  • Reference files are fine for all of them to see.
  • Rerun the three tests after every change.
  • Your name on it as maintainer, and a review date.

ACTIVITY 3 · ~12 MIN

Choose a Task to Schedule, and Set One Up

A scheduled task runs a prompt at a set time and sends you the result. Most tasks shouldn't be scheduled.

ACTIVITY 3 · THE TEST

Worth Scheduling Only If All Four Are True

It repeats

On a fixed schedule: weekly, monthly.

Public information

Or only what you write in the prompt. Scheduled tasks can't read your Project files.

You'll read it

A task no one reads still runs and still uses time and energy.

Wrong is cheap

You'll catch a bad result, and no one else acts on it.

ACTIVITY 3 · PART B · 8 MIN

Set Up One Scheduled Task

  1. 1ChatGPT Edu: open Scheduled in the left sidebar.
  2. 2Paste the prompt. Fill in your topic and an end date.
  3. 3Check the name, day, time, time zone, and how often.
  4. 4Settings → Notifications: push, email, or both.
  5. 5When it runs, open every link before you use it.
The promptEvery Monday at 8 AM Eastern, search PubMed and the web for articles published in the past 7 days on [your topic]. List up to 5, with title, journal, publication date, and link. Only include articles you can link to. If there is nothing new, say "Nothing new this week." Stop running this task on [date three months from today].
Ask yourselfIf this task stopped working, would I notice? If not, I won't notice a wrong result either.

ACTIVITY 3 · LIMITS

Scheduled Tasks: What to Know

ChatGPT Edu
  • Up to 10 active tasks; no more than once an hour.
  • A task made in a Project can't read the Project's files.
  • Each run uses your allowance, even with nothing to report.
  • Results come only to you. Don't schedule messages to others.
  • Check monthly. Pause or delete what you stop reading.
Other tools, and more ideas
  • Copilot Chat: scheduled prompts need the paid license. Not available at Drexel.
  • Monthly: a funder's announcements page.
  • Weekly: new state or city reports on a policy you follow.
  • Each term: recent articles for a course reading list.

WRAP-UP

What to Take Away

Write it once in your own document. Test it before you share it. Schedule only what you'll read.

  • In ChatGPT Edu, plugins replace custom GPTs. Copy out any custom GPT instructions before December 11.
  • Test every assistant three ways: out of bounds, push back, missing information.
  • Schedule a task only if it repeats, uses public information, you'll read it, and a wrong result is cheap.
  • Claude and other personal tools: Low Risk Data only.

In the Zoom chat: one assistant or one scheduled task you'll set up this month.
